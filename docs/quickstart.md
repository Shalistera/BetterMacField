# BetterMacField 使用说明

1. 在 PlayCover 安装国服或国际服 iOS 1.6.3，在游戏设置 →「绕过」中开启「Block SleepSpamming」，再从 PlayCover 成功运行一次游戏，下载完资料后退出。
2. 解压并打开 BetterMacField，阅读风险提示后选择是否使用，再选择对应服。
3. 调整画面、光影和操作设置，点击「启动游戏」。

运行中修改设置后点击「保存并应用」。Metal HUD 显示选项在下次启动生效。

超分模式默认使用 **MetalFX Spatial**，菜单依次为 Spatial、Temporal、TAAU。Temporal 画面更好，但可能存在 bug；已有的手动选择会保留。

「植被密度」提供游戏默认、50%、70%、100% 四档，默认 100%。它调节当前移动端场景已有草丛、芦苇等植被的显示密度，使用已安装的游戏资源。启动器和游戏内菜单都可修改；选择「游戏默认」会恢复游戏原有密度。

⌘G 切换原生／增强画面，再按恢复。默认同时切换至 TAAU＋50% 渲染和手机 LOD，可在「操作」页取消这两项。输出分辨率保持不变。LOD 的远景更新可能有延迟。

滚轮缩放镜头；按住 Alt／Option＋滚轮选择交互项。长按 R 打开工具转盘。

「状态与恢复」可校验客户端、复制诊断信息。诊断信息包含当前错误和已有运行日志，游戏尚未启动时也可复制。退出游戏后可恢复 PlayCover 设置。直接从 PlayCover 启动即使用原版。

如果提示「游戏版本与当前 BetterMacField 适配的版本不同」，请查看详情中的已安装版本和支持版本，按下载页说明选择匹配的工具版本与 IPA。

同版本客户端使用不同签名时可直接启动。启动遇到问题时，请先确认已在 PlayCover 开启「Block SleepSpamming」，并成功运行过一次游戏；点击「复制诊断信息」可将错误反馈给发布者。

启动时遇到版本匹配提示，可以选择「返回检查」或「仍然启动」。选择「仍然启动」会忽略本次启动的版本匹配提示，继续加载增强功能。命令行可使用 `--launch --force`；`--check --force` 可校验其余组件。

此包采用本地签名。首次打开若被 macOS 拦截，可在「系统设置 → 隐私与安全性」中允许打开。
