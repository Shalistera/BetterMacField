# BetterMacField 使用说明

1. 用 PlayCover 安装国际服或国服 iOS 1.6.3，先正常启动游戏、下载完资料，然后退出游戏。
2. 解压安装包，打开 `BetterMacField.app`。
3. 右上角选择对应服，在「画面」「光影」「操作」中选择需要的功能。
4. 点击「启动游戏」，正常登录进入场景，设置会自动应用。玩家无需 Python、Xcode 或终端。

启动器可以保持打开。修改后点击「保存并应用」即可发送给当前增强版游戏；顶部 BetterMacField 菜单也提供相同选项。两服分别保存设置。「启动时显示 Metal HUD」在下次启动生效，运行时可使用游戏顶部的 Metal HUD 菜单。

画面包括输出分辨率、TAAU / MetalFX Temporal / Spatial、质量/平衡/性能、锐化、LOD 加载距离。光影包括角色自阴影、角色光照与滤波、阴影精度、GTAO、接触阴影、SSR，以及可单独选择的实验性 PC 高光公式。操作包括自动键鼠、后台节能和 Metal HUD。

0.3.2 测试版首次默认使用 1080p、质量档、MetalFX Spatial＋原生 TAAU 抗锯齿；角色光影、GTAO、接触阴影开启，SSR 与实验性 PC 高光关闭。Spatial 当前组合存在移动拖影。已有配置继续保留，升级后可在「超分模式」中选择 Spatial。高负载时先选性能档或降低输出分辨率。后台节能开启时失焦为 15 FPS，性能对比应保持游戏在前台。

## 录制光影对比

按 F11（部分键盘需 Fn+F11）或 ⌘⇧G，也可以点击 Launcher 的「光影对比」按钮。

第一次临时回到游戏原生光影：关闭额外 GTAO、接触阴影和 SSR，恢复原有自阴影门槛、角色着色模式和阴影精度。再按恢复切换前的增强设置。临时对比不会覆盖保存的配置。

分辨率、超分和 LOD 保持相同，便于同机位展示光影差异。整个原版客户端对照可在退出游戏后直接从 PlayCover 启动。

## 恢复与状态

「状态与恢复」显示实际光影执行次数、错误计数和连接状态，可校验客户端或复制日志。

退出游戏后，点击「恢复 PlayCover 设置」，即可恢复本工具调整的 UI 缩放、窗口比例与按键映射选项。每个服只保留一份恢复记录，保留玩家后来单独改过的值。

直接从 PlayCover 启动时不会注入 BetterMacField。Launcher 不修改客户端二进制或资源包。

## 当前边界

- 客户端校验支持国际服与国服 1.6.3 的指定构建；更新后需要对应适配。
- 默认使用 Spatial，当前组合存在移动拖影。Temporal 保留实验入口；macOS 27 上的早期精简核心与完整开发版均曾发生 Temporal / ANE 异常退出，触发条件尚未确定。
- LOD 改回手机档会恢复参数，已经驻留的内容由游戏管理，画面可能需移动或切换场景才完全更新。
- 包含光影运行所需的渲染程序及绑定信息；不包含 MOD、模型、贴图或资源替换工具。渲染程序中的游戏原始代码不属于本项目 MIT 授权范围，来源见 NOTICE。
- 当前采用本地签名，尚未通过 Apple 公证。下载后的首次打开可能被 macOS 拦截。先核对来源与 SHA256SUMS.txt；系统允许时，可通过「系统设置 → 隐私与安全性 → 仍要打开」打开。

日志在 `~/Library/Containers/<客户端 ID>/Data/tmp/BetterMacField/bettermacfield-runtime.log`。
