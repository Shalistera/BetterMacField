# BetterMacField 0.6.1 使用说明

适配国际服和国服 iOS 1.7.2 / build 0。国服尚未进游戏验证，不要使用 1.6.3 客户端。

1. 通过 PlayCover 安装游戏，在「绕过」中启用 **Block SleepSpamming**，成功运行一次、下载完游戏资料后退出。
2. 解压并打开 BetterMacField，阅读风险提示。只安装一服会自动选择；两服都在时，选择要使用的客户端，再在「高级 · 维护」点「校验客户端」。
3. 在「画质」页选一个画质预设（流畅／推荐／极致），需要时再单独调整，点击「开始游戏」。其他同服游戏必须先退出。

首次启动会准备独立的 PlayCover 游戏副本，耗时比后续启动更长。源安装目录保持原样，副本继续使用原游戏容器中的下载资料与游戏设置。退出增强会话后，从 PlayCover 启动即可使用原版。

设置改动立即保存；游戏运行时会直接应用，标有「下次启动」的选项在下次启动游戏时生效。窗口可拖动边缘缩放，**⌘⌥P** 打开游戏内菜单。超分默认 MetalFX Spatial，也可选择 Temporal 或原版 TAAU。Temporal 使用原生颜色、深度、运动矢量和抖动输入，并保留原生环境光与地形深度。

**⌘G** 切换原生／增强画面，再按恢复。默认同时切换至 TAAU＋50% 渲染和手机 LOD，可在「高级」页分别关闭；输出分辨率保持不变。远景 LOD 更新遵循游戏流送，可能稍有延迟。

滚轮缩放镜头；**Alt／Option＋滚轮**选择交互项；长按 **R** 打开工具转盘。植被密度控制当前场景已有的草丛，选择「游戏默认」恢复原有密度。

「高级 · 维护」可校验客户端、复制当前诊断信息；退出游戏后可恢复本工具对所选区域修改的 PlayCover 设置。支持客户端重新签名，代码身份不匹配时需使用对应适配版本。旧版 1.6.3 支持已结束。

自定义键位页、120 FPS 解锁与缺失场景植被恢复尚待新版适配；公开包不含角色模型替换、衣装或 MOD。

应用采用本地签名，首次打开若被 macOS 拦截，可在「系统设置 → 隐私与安全性」中允许打开。后续更新的逐项验收要求见仓库 docs/update-checklist.md。
