# 场景植被恢复与 iOS 资源复用

截至 2026-10-25，这轮公开版准备工作的重点是区分原生参数控制、缺失场景实例恢复和 PC 素材移植。自用版已接入的 55,160 个静态植被实例中，51,563 个可使用 iOS 自带模型、材质和贴图；它们的新增场景记录目前仍取自 PC。0.4.0 已完成这部分的独立候选构建及国际服独立启动检查。

## 这些树属于什么

| 对象 | 已确认的数据结构 | 与画面设置的关系 |
| --- | --- | --- |
| 草丛密度系统 | `GrassGrid_`，场景记录类型 7，草实例成组保存 | 公开版现有密度控制使用 `GrassGlobalSparsity`，调整已有草丛等内容 |
| 本次恢复的静态植被 | 场景记录类型 9，带独立变换、模型／材质引用、LOD 和分块归属 | 对应 iOS 分块缺少实例记录，调密度或加载距离不会新增这些记录 |
| 远景植被和成组模型 | 本次候选也包含 `farmod`、`group` 等命名的静态实例 | 与普通场景树分别统计；名称不能单独证明它受哪个画质档位控制 |

给小桌子投影的树是 `P_tree_map02_shanshu+1_001_02`，实例 ID 为 `1346272745`。它的模型、材质引用均存在于 iOS 资源表，PC 场景专属分块保存了手机分块缺失的摆放记录。恢复实例后，投影由游戏原生阴影系统产生。

用户在 PC 上调低植被和场景细节后仍看到这些树，这与固定场景物件的判断吻合。当前证据能确定两端场景数据有差异；制作时采用了哪种移动端导出／裁剪规则，以及 PC 每个菜单项具体控制哪些对象，还需另外对应。

55,160 个实例按名称前缀分为：`bush` 25,929、`tree` 15,481、`vine` 6,788、`grass` 3,851、`farmod` 3,066、`itree` 27、`group` 18。这里的 `grass` 也是静态物件记录，与上述 `GrassGrid_` 批次分别处理。这些计数描述资源命名，不作为引擎质量层级的判断依据。

## 原生素材候选的实际依赖

51,563 个实例的“原生复用”指美术素材来自 iOS。维护者构建时仍读取 PC 场景分块；玩家使用准备好的安装包和已安装的 iOS 客户端。摆放记录来自 PC，当前成果并非完全从 iOS 场景数据重建。

`prepare_vegetation.py` 从官方 iOS 输入生成独立覆盖，`tools/scene_vegetation.py` 重新序列化选中实例的定义、分块归属和 ECS 数据。Streaming 字段按实际类型复制标量、资源引用和嵌套字节数据；没有携带未选中的 PC 输入缓冲区，也没有沿用自用版的旧覆盖。所有非空模型／材质资源引用均经过 iOS 资源表检查。Init／Streaming 配对构建、原有实例保留、组件与引用一致、压缩往返检查均通过。

本地研究导出输入包含：

- `graphics-ios-vfs-1.6.3.jsonl`、`graphics-pc-vfs-1.6.3.jsonl` 及其中引用的官方 `.chk` 文件；
- `graphics-ios-manifest-1.6.3.raw`；
- `world-vegetation/release-classification.json`、`world-vegetation/native-descriptors.json`。

维护者安装 Python `lz4` 后运行：

```sh
python3 prepare_vegetation.py /path/to/local/research-export
python3 build_release.py
```

输出位于 `build/Vegetation`，约 405 MiB，包含 1,054 个场景分块和清单。它是本地打包输入；公开 Git 仓库只保存代码、构建工具与说明，原始导出、生成数据和发行 ZIP 均被忽略。游戏衍生内容的归属见 [NOTICE](../NOTICE)。当前工具消费维护者已有研究导出，面向任意玩家安装目录的素材提取流程仍未提供。

国际服 iOS 1.6.3 已用公开运行模块独立进入场景，1,054 个分块成功挂载，未接入自用版 PC 模型包与资源替换桥接；场景粗查可见树木和树影，未见大块地面或模型缺失。国服本地 1,054 个原始分块与该包输入逐一核对，全部一致；场景包与功能入口同时支持国服和国际服。特定新增实例的逐场景观感与远景样本仍待后续验证。

功能默认关闭，设置在下次启动生效。运行时只替换内存 VFS 路由与对应松散分块，官方 `.chk` 保持原样。覆盖前将原有松散文件与恢复记录保存在客户端持久目录；正常退出自动恢复，异常退出后可通过启动器恢复。实测 1,054 个原有松散分块全部恢复，文件摘要与测试前一致，恢复记录已清理。

## 调试设置归属

`EndfieldIgnoreGamepad` 用于本地调试时屏蔽手柄干扰，保留在自用调试环境。公开版的功能表、默认配置和发布说明不加入这一项。

公开版 `src/input_auto.inc` 已去掉 `input_tune` 中的 `controller=false`，保留用户的手柄启用偏好。国际服键鼠进场与按键页面已确认；手柄与键鼠反复切换仍需实际操作复核。

CSM、ASM、GTAO、接触阴影的临时单项关闭属于定位实验；产品控制项继续按各自已有实现与验证状态处理。

## 当前验证与清单

自用版已完成全量分块构建检查，原有实例保留、新增 PC 记录及引用匹配、压缩往返检查通过。国际服 iOS 1.6.3 实际进入桌边场景，147 个模型加载成功，地面树影可见。该自用版记录与本页新增的独立候选检查分别记录；其他地图的实际观感尚待验证。

在本地研究工作区使用研究环境的 Python 执行 `ios-mac/world_vegetation.py --classify-release`，可重新导出 `ios-mac/build/world-vegetation/release-classification.json`。清单逐分块保存两类实例 ID、各地图数量、缺失资源和数据缺口，供后续构建筛选；生成的研究清单保留在本地构建目录。
