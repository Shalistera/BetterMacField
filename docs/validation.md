# 0.3.5 验证记录

当前发布范围为启动器与图形／输入集成源码。此页只记录当前版本沿用的验证结果与限制。

环境：Apple M1 Max、macOS 27、PlayCover/PlayTools。验证使用国际服 iOS 1.6.3（OS_IOS_REL_1.6.3_C1078149_E10704668）和国服 iOS 1.6.3（CN_IOS_REL_1.6.3_C10781849_E10704668）。

## 已验证

- 国服与国际服均曾通过完整启动器进入场景，Spatial、GTAO、接触阴影执行计数持续增加，抽查期间 GPU 错误为 0。国服雪地与国际服场景粗查未发现地面缺失；这些短测不代表全地图或长期稳定性。
- GTAO 使用游戏原版深度重建法线变体，避开移动端地形未写入材质法线的问题。此前马赛克改善已由用户目测确认。
- 国际服实际完成 ⌘G 对比往返：Spatial／66.7%／PC 高档 LOD → TAAU／50%／手机 LOD → 原配置，角色光照、自阴影、GTAO、接触阴影、SSR 和阴影精度同步恢复，保存的增强偏好保持不变。关闭两个对比选项后，超分与 LOD 保持原值。国服此前完成光影对比；最新两项扩展未单独进入国服复测。
- 用户确认滚轮能将镜头移近。公开版滚轮控制镜头，Alt／Option＋滚轮选择交互项。
- 0.3.5 启动器实测显示风险提示，初始“使用”按钮禁用；主界面可进入。“下次不提示”及“不使用”分支尚未完成独立交互复核。
- “实验性功能”页两个按钮呈灰色，分别点击均弹出“暂未开放”；它们没有接入模型或 MOD 执行逻辑。
- 包内 1024 像素图标与指定 PNG 完全一致。版本为 0.3.5 / build 8，启动器和包内文件一致，代码签名校验通过。
- 隐藏 UID 选项及运行实现已从当前源码和构建中移除。
- 启动器自动测试覆盖客户端签名差异、PlayTools 依赖检查、版本处理、恢复记录、安装目录隔离、两服运行目录隔离和包内组件校验。签名差异使用临时客户端文件模拟。

## 当前限制

- 默认超分模式为 Spatial；当前 Spatial 与游戏抗锯齿组合可能存在移动拖影。Temporal 为可选模式，TAAU 位于菜单末尾。
- 2026-10-25 维护者反馈：正式版经过多次修复，个人使用 Temporal 基本未遇到问题。界面提示为「Temporal 画面更好，但可能存在 bug」。
- 历史记录：早期 Temporal 曾在 macOS 27 的 MPSGraph／ANE 异步推理链路中断言退出；超分器改为复用、仅在尺寸变化时重建后，短测通过。早期实验还发生过一次 GPU 固件系统重启，与 Temporal 的因果关系尚未确定。
- LOD 的已驻留资源由游戏流送及释放，不能保证当帧得到完全一致的移动端对照。
- 未覆盖所有地图、角色、战斗状态及 macOS 版本，也尚未在另一台 Mac 验证首次下载后的系统拦截行为。
- 应用采用本地签名，尚未 Apple 公证。
- 完整光影包依赖未提交的本地渲染程序导出；源码可编译动态库，不代表仅克隆仓库即可重建完整包。见 README 与 NOTICE。
