# 首版验证记录

环境：Apple M1 Max、macOS 27、国际服 iOS 1.6.3（OS_IOS_REL_1.6.3_C1078149_E10704668），通过 PlayCover/PlayTools 运行。其余客户端构建与系统版本尚未实机验证。

## 已验证

- 从此仓库源码独立编译 arm64 动态库，未读取原开发目录、模型转换结果、高清贴图或外部着色器文件。
- 启动器确认 UnityFramework / metadata SHA-256 与 PlayTools 加载项，启动后进入真实场景。
- 顶部画面菜单出现角色自阴影、阴影精度、分辨率、超分档位、TAAU/Temporal/Spatial、LOD、自动键鼠。
- 角色自阴影通过原生 Volume 开启；关闭再打开，`overrideState` 与运行状态同步恢复。
- 独立核心中的 Temporal 在实际场景连续编码，已观察到超过 2400 帧、0 个 GPU 错误；输出尺寸从 1280×720 切换到 1920×1080后继续编码。
- 抖动修复在原开发进程中先做同帧 GPU 对照，再由用户试玩确认“消失或明显减轻”。稳定远景的横向位移范围从约 0.571 降至 0.079 像素；同帧原版 TAAU 约 0.079–0.098 像素。独立核心采用同一修正。
- 最终重启自动恢复 Temporal、1920×1080 输出与 1280×720 场景输入；键鼠桥接记录 `input_auto_activation=ready`，场景截图显示完整桌面 HUD 与原版角色。后台首次进入场景保存的前台上限为 60，而非登录界面的 30。
- 四项启动器边界测试通过：二进制变更拒绝、未知版本拒绝、单份设置恢复保留用户后续修改、第二安装目录不能覆盖恢复记录。

## 已知边界

- Spatial 是备选，当前沿用的原版 TAAU 抗锯齿组合有明显移动拖影。
- 额外 SSAO、接触阴影、SSR、PC 角色高光公式不在此源码核心中。
- LOD 参数恢复后，已驻留资源由游戏自行释放，不能保证当帧得到完全一致的移动端对照图。
- 本次未覆盖所有地图、角色、战斗状态及 macOS 版本；运行通过和 GPU 无错误不等同于全部画面已经无瑕疵。
