# BetterMacField 验证记录

## 0.6.0 / 国服 1.7.2（仅离线，尚未进游戏验证）

本次核对的是国服 iOS IPA 与国际服 PlayCover 安装。二者都是 1.7.2 / build 0，但不能共用原生代码地址。0.6.0 同时还改版了启动器界面与游戏内菜单（只改布局、名称和预设，设置键值和默认值不变）；新菜单尚未在游戏中打开验证。

| 核对项 | 离线结果 |
| --- | --- |
| 构建身份 | 国服 `com.hypergryph.endfield` 和国际服 `com.gryphline.endfield.ios` 的 arm64 UnityFramework UUID、`__TEXT,__text` 哈希均不同；v29 IL2CPP metadata 逐字节相同。确切身份见 `clients172.py`。 |
| 渲染与输入入口 | 三个原生渲染回调及 C++ 渲染路径开关的 wrapper、getter、数据地址按区选择；两个构建都符合原有指令检查。10 个键鼠查询入口按同一 metadata 定位，国服各移 4 字节。不据此推断回调已触发或游戏已收到输入。 |
| 随包资源 | `Data/` 的 577 个文件路径相同，仅 `boot.config` 的区域配置不同。`Data/Raw` 的 552 个文件逐一相同。核对 16 个源 bundle，覆盖 6 个角色与 24 个场景片元、64 个场景变体、100 项摄像机绑定、16 个 GTAO 和 6 个接触阴影 kernel。两区共用 59 个导出文件；从国服重新生成的原生清单列出 74 个深度消费者。此比较不含之后下载的热更新。 |
| 打包 | arm64 macOS launcher / graphics 与 Mac Catalyst entry 编译、链接通过。两个组件使用同一份区域表；深度签名、65 项 payload 哈希及 ZIP 校验通过。15 项离线测试通过。 |
| 客户端校验 | 0.6.0 的只读 `--check` 接受国服 1.7.2 解包目录与国际服 1.7.2 安装，拒绝已安装的国服 1.6.3 和交叉区域。临时双区环境中恢复国服后，国际服设置与恢复记录逐字节不变。 |

**未做国服实机验收。** 没有安装或运行国服 1.7.2，未观测 PlayCover 转换后的代码、插件激活、场景、GPU 编码、键鼠操作，也未改动真实 PlayCover 设置。试用时先从 PlayCover 启动国服原版一次，下载完资料并退出；打开 0.6.0、选择国服，先在「高级 · 维护」校验客户端，再启动。以下国际服的实测数字不适用于国服或 0.6.0 的新界面。

## 已发布的 0.5.0 / 国际服 1.7.2

本轮新增国际服 1.7.2 / build 0 专用原生启动及运行模块；按当前发布范围移除 1.6.3 模块、旧资源和区域切换。

- 移植源已实机场景验收：MetalFX 开启后氛围恢复，Temporal 静止远景抖动消除，地面材质恢复。原生 Temporal 采样从 2560×1440 输出至 3840×2160，完成 1,596 次且 GPU 错误为 0；6 个 GI 体积输入存在，深度 resolve 1,614 次、消费者绘制 7,012 次、缺失计数 0。这是移植前已验收实现的证据，公开包实测单独记录。
- 1.7.2 导入 59 项经过哈希校验的渲染程序文件，包内仅保留新版运行组件和渲染输入。
- 1.7.2 自定义键位页、120 FPS、缺失场景植被恢复尚未移入，当前界面移除。PC 高模、衣装和 MOD 不在公开版范围。
- 公开 0.5.0 / build 10 的 macOS graphics bundle、macabi entry、原生 launcher 构建和深度签名校验通过。13 项自动测试通过：12 项原生启动/身份/组件/恢复测试，1 项运行时测试含 14 条行为断言。纯运行组件可在没有外部渲染资源时独立构建。
- 公开包实际创建隔离副本并进入场景，session `89412209-2360-4481-9E3A-F4C673B16617`，1.7.2 渲染参数成功应用。Temporal → Spatial → Temporal 实际往返，恢复原设置；采样累计 1,136 次编码全部完成，Spatial 180 次，GPU 错误 0。
- 公开包原生 GI 有效绘制 4,536 / 4,536；深度 resolve 1,134 次，地形/Decal/Visibility 消费者绘制 11,340 次，缺失计数 0；GTAO、接触阴影和 SSR 各 1,134 次，错误均为 0。
- 公开场景用户确认「地面与氛围都正常」。移植前私人版的静止远景稳定性已由用户确认；本次公开包补充了实际进场和两种超分模式往返。
- 最终包 65 项 payload 哈希与 ZIP 校验通过，压缩包约 2.9 MB；包内无旧 Graphics/Vegetation/运行库。当前 Git 清单只提交项目源码、文档与图标。

## 验证边界

主要环境为 Apple M1 Max、macOS 27、PlayCover/PlayTools。没有覆盖全部地图、角色、战斗状态和 macOS 版本。当前应用采用本地签名，未 Apple 公证。完整包依赖维护者准备的本地渲染程序导出；仅克隆仓库可以编译项目运行组件，不能重建游戏派生输入。

独立 GPU 测试的 Spatial 编码成功不等于全部实际场景验收；各模式以本页记录的实际验证为准。
